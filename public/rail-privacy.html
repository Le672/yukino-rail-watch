Yukino 余票

隐私政策

适用于 Yukino 余票 Android / iOS 客户端 · 生效日期：2026 年 9 月 30 日

开发与维护者为 Yukino（GitHub：Le672）。本应用查询公开余票、车型、停站时刻，并提供到票提醒和列车位置辅助判断。无需注册，不登录 12306，不处理身份证、旅客姓名、订单或支付信息。

1. 查询与本机保存

  • 你填写的车次、出行日期、出发站和到达站会发送给 Yukino 查询服务，由服务向 12306 获取公开余票。车型和运行资料由客户端直接向 RailGo 查询。
  • 查询条件、所选席别、检查间隔、最近结果及用于避免重复通知的余票状态保存在应用私有存储。关闭监控可停止后续自动查询；卸载应用可清除这些本机记录。
  • 应用没有广告、账号体系或用户行为统计 SDK，不创建用于跨应用追踪的广告标识。HTTPS 服务商在处理请求时可接收到 IP 地址、请求时间和请求路径等基础网络信息，相关日志由各服务商按其政策管理。

2. GPS、速度和地图

  • 只在你点击开启 GPS 后申请定位权限。位置页面可见且应用在前台时读取坐标、精度、速度、方向和时间；用于在设备上计算线路位置、下一停靠站和实时速度。
  • 停止定位、离开位置页或进入后台会停止位置监听。本应用不申请后台定位，不保存位置轨迹，不向 Yukino 或 RailGo 上传设备的精确坐标。
  • 地图需要向第三方请求当前视野的瓦片；请求包含瓦片坐标和 IP 地址，地图服务商可能据此推断你查看的近似区域。启用位置跟随后，这一区域可能接近设备所在地。该地图请求不等同于上传完整 GPS 轨迹。
  • 拒绝定位权限仍可使用余票查询、时刻表位置和标明来源的预估速度。地图和测速仅用于辅助参考。

3. 通知与后台检查

开启监控时申请通知权限。提醒内容包含车次、日期、乘车区间及关注席别的余票情况，由设备发送本地系统通知，不注册 APNs、FCM 推送令牌。

后台任务仅查询公开余票。Android 后台周期最短约 15 分钟，可能受省电和网络限制而延迟；iOS 的后台检查由系统安排，无法保证固定频率，强制退出后不会继续检查。打开应用时按所设 1–60 分钟间隔检查。

4. 使用的服务

Yukino 查询服务 / Cloudflarewww.yukino.bond/api/rail · 接收查询条件并提供 12306 公开结果；网络传输与托管由 Cloudflare 提供。
12306中国铁路 12306 · 公开余票数据。点击购票网站链接后，后续操作适用 12306 自身政策。
RailGo Data Service数据服务说明 · 接收车次、日期或区间，用于车型、停站、线路与正晚点查询。
OpenStreetMap / EOXOpenStreetMap 隐私政策 · 2D 地图；EOX::Maps · 卫星影像瓦片。接收当前地图视野的瓦片请求。

5. 你的选择与联系

可随时关闭监控、停止 GPS，或在手机系统设置中撤销通知和定位权限。权限撤销不会影响基础余票查询。清除应用数据或卸载应用可移除本机保存的信息。

如有隐私问题或需要协助，请联系 Raptor@yukino.bond。代码与问题反馈见 GitHub 项目。数据使用范围改变时，本页会更新生效日期并在应用更新说明中说明。
