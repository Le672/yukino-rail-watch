# Yukino Rail Watch 1.9.0

- 新增中转行程，支持同站、广州南／番禺等相邻站群及明确标注的长株潭站外衔接；最多两次中转、三程列车，支持指定节点和换乘预留。
- 每程展示真实站名、日期、时刻、余票、官方票价与车型插图，处理跨日到达、再次安检和检票时间。
- 余票与中转支持票价、总耗时、出发／到达时间、余票及车型排序，支持有票与车型筛选。
- 从 12306 余票价格编码读取报价，必要时查官方票价接口；未知总价不计为零元，城际不对号票价单独核实。
- 严格过滤官方响应中的同城其他车站，保留独立 Windows 界面与托盘通知。
