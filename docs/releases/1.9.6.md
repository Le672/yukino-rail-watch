# Windows 1.9.6 · 国内 2D 地图修复

- 列车位置页 2D 底图默认使用高德国内服务，显示中文地名；保留 OpenStreetMap 备用来源。
- 铁路线路、停站、GPS 和地图中心随底图统一转换坐标；切换卫星图保持当前视野与缩放，GPS 匹配和测速使用原始 WGS84 数据。
- 连续失败或 15 秒未取得瓦片时显示提示，可重试或切换底图；适配窄屏来源选择器。
- 保留独立 Windows 布局、托盘余票监控和系统通知，官方车次、车型与停站查询规则不变。
