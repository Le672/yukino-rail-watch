# Yukino Rail Watch 1.9.3

- 升级后自动刷新缺少城市标识的旧车站缓存，让已有网页、桌面和手机用户立即获得全国同城资料。
- 中转候选扩展到全国所有 12306 官方车站，不限制广东、湖南或省会；按当日官方推荐、全国铁路干线和城市站点发现路径。
- 全国同城不同站按站外交通衔接，北京、上海、成渝、东北、西北、西藏、海南等地区均可查询；保留已核实相邻站群的独立步行预留。
- 默认检查 64 个候选站，可扩展至 128 / 256 / 512 站；显示候选范围、未完成区间和扩大范围按钮，也可指定任意官方中转站。
- 同城不是邻站；未核实城区范围的车站保守预留至少 180 分钟，地面交通路线需自行确认，费用不计入铁路票价。
- 官方余票请求增加间隔并合并会话初始化；连续失败停止继续请求，保留已获取的方案并提示重试。
- 每程仍显示车型、时刻、官方票价与余票，保持总价／耗时／余票／车型排序筛选和独立桌面布局。
