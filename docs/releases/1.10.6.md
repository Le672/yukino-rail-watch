# Windows 1.10.6

- 修复中转页长期保留过期乘车日期、导致余票查询连续返回 423／502 的问题。重新打开时只将已过期的日期更新为今天，并保留车站和换乘条件、提示核对日期。
- 日期选择范围采用北京时间当天至后 14 天。客户端和服务端均在查询前验证，过期或超出预售期时显示具体原因。
- 跨日中转的衔接程尚未进入预售期时停止该日期请求，并注明未开售，不将其作为没有列车或上游故障。
- 历史始发日的位置、停站表和大屏查询保留原有规则；继续使用独立 Windows 桌面布局。

下载 `Yukino-Rail-Watch-1.10.6-portable.exe` 后直接运行。`SHA256SUMS.txt` 提供文件校验值。
