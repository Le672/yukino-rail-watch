# Windows 1.9.5 · 官方车次与车型

- 按车次搜索漏项时读取 12306 按日期车次表，精确匹配、去重并检查多线路歧义；余票和位置查询共用官方检索。
- 余票、中转和位置页优先显示 12306 计划车型及客运担当。官方车型已存在时不请求 RailGo，缺少车型才补充参考资料。
- 车型按首站始发日查询，支持跨日乘车；无日期绑定的车型标为参考。客运担当与车辆配属分别展示，具体车组可能调整。
- 官方车组号优先用于动感号涂装核对；保留独立 Windows 布局、托盘监控和系统通知。
