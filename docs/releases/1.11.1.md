# Yukino Rail Watch v1.11.1

- 包含 v1.11.0 的全国有向轨道接驳扩展、铁路枢纽与方向排序、候选名单之外的跨城连接、两次轨道接驳，以及最短轨道方案比较和直接入口。
- 修复今日行程可行性：将出发地铁／站群步行、候车和铁路进站预留扣除后，若实际出发时间已过去则排除该方案，不再仅依据铁路列车尚未发车判断可以赶上。
- 今日纯轨道行程从当前时间或用户设置的更晚时间开始；未来日期仍按设定的最早出发规划。保留进站预留、跨日日期、取消和未完成区间提示。

城市轨道继续默认关闭，铁路默认优先；首末班、运营日期及轨道票价未知时仍需核对。保持独立 Windows 界面，此次只更新网页和 Windows；Android／iOS 继续暂停。
