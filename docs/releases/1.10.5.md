# Windows 1.10.5

- 修正 GPS 瞬时速度的判断：系统返回的有效速度不再因坐标误差较大而丢弃；分别标注设备瞬时读数、GPS 短时测速和时刻表预估，无法实测时显示具体原因。
- 车次可留空，开启 GPS 后结合连续轨迹、本站铁路缓存和附近车站的 12306 到发车次进行推断。足够明确时自动显示行程与下一站；候选重合或资料缺失时保留候选，点击即可选择。
- 地图同时显示设备位置与带车次标签的绿色列车位置。GPS 无法匹配时仍显示明确标注的预估位置，新增“列车位置”视图按钮。
- 较粗的 GPS 信号可以近似匹配铁路；误差范围跨越停靠站时保留时刻表的下一站依据，避免错误跳站。
- 保留独立 Windows 桌面布局、余票托盘通知和全国铁路网缓存。

G3762 的官方时刻表与公开路径合成轨迹已核验：2026-10-07 15:03 的候选首位为 G3762，下一站为佛山西。这不是用户真实 GPS 轨迹或实车测速证据。

GPS 不能保证唯一识别车次。系统没有速度且定位误差过大时，无法可靠获得实测速度，页面会继续显示明确标注的预估值。

## 下载与校验

下载 `Yukino-Rail-Watch-1.10.5-portable.exe` 后直接运行。`SHA256SUMS.txt` 提供文件校验值。
