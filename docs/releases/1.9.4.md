# Yukino Rail Watch 1.9.4

- 新增全国城市轨道可选接驳：地铁、轻轨、有轨电车、单轨、磁浮、市域轨道、APM 与轨道缆车，不使用城市白名单。
- 默认关闭且铁路方案优先，可选择轨道站为起终点，或组合铁路与城市轨道；可手动改为按票价／耗时等统一比较。
- 显示每条轨道线路的上下车站、站序、换线、估算耗时和待确认运营资料，进入铁路另加检票预留。
- 轨道票价不明时完整总价保持未知，铁路小计单列；不伪造车型、实时班次及余票。
- 全国 2026-10-03 开放网络快照按需载入、本机规划；保留独立 Windows 桌面布局。已收录线路不保证无遗漏，首末班和停运须运营方确认。
