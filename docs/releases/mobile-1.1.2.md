# Android / iOS 1.1.2 Preview

- 中转扩展到全国官方车站和同城异站，支持各地 12306 城际／市域、高铁与普速多程组合。
- 自动更新旧版车站缓存，升级后即可识别全国同城异站。
- 新增全国候选覆盖数及扩大搜索范围，城区与未核实城区范围的站点分别预留，实际车站和交通段明确显示。
- 保留逐程车型、时刻、票价、余票及整体排序筛选，与网页和 Windows 使用同一规划规则。

## 附件用途

`*-debug.apk` 可用于 Android 测试安装；`*-unsigned.aab` 尚未签名，不能直接安装或上传商店。

`*-simulator.zip` 仅供 Mac / Xcode iOS 模拟器使用，不是 IPA，不能安装到实体 iPhone。真机、TestFlight 与 App Store 需 Apple 开发者账号签名。
