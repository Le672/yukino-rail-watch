# Windows 1.10.12

- 支持两段铁路之间的完整地铁行程，显示线路、换线站、途经站与步行候车及进站预留；全国已收录轨道网络使用同一算法，城市轨道仍为可选备选。
- 指定中转站必须经过实际枢纽或已核实相邻站群，不再把广州新塘替换为广州全市其他站。
- 补齐 12306 车站文件遗漏的惠州北、佛山西和肇庆城际独立代码。广州南到番禺步行换乘后，能查询番禺到惠州北城际；每程余票、时刻和票价仍直接查询 12306。
- 两个指定中转站的结果与“减少中转备选”分开显示，明确说明未经过第二中转站，不改动原查询条件；可直接筛出含地铁／城市轨道的方案。
- 保留独立 Windows 界面及既有查询恢复、地图、实时位置与车站大屏功能。移动端继续暂停。

下载 `Yukino-Rail-Watch-1.10.12-portable.exe` 后直接运行。`SHA256SUMS.txt` 提供校验值。
