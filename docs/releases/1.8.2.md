# Windows 1.8.2

- 修复 exe 加载网页入口的问题，新增独立桌面入口与界面，后续网页改版不再替换桌面布局。
- 左侧功能导航、紧凑查询工具栏、车次表格、后台监控状态和底部状态栏；移除网页大标题、主站导航与站点页脚。
- 保留车次 / 区间查询、Windows 通知与托盘监控、车型插画、GPS 地图、下一站和实时 / 预估速度。
- 窗口默认 1280 × 820，最小 920 × 640；窄窗口下监控面板移到结果下方，表格可滚动。

下载 `Yukino-Rail-Watch-1.8.2-portable.exe` 运行即可。关闭旧版后启动新文件；监控设置仍使用原有本地配置。
