# Windows 1.10.4

- 列车位置地图新增本站服务器缓存的全国铁路网，包含国铁、地方铁路、广东等地区城际和香港高铁段，不包含地铁、轻轨、有轨电车等城市轨道交通。
- 按官方停站顺序沿实际轨道连接推定路线，使用完整几何计算预估位置和区间距离；不将立交或相邻轨道强行连线。G4695、G2789 及跨地区铁路连接已核验。
- 地图提供“铁路网”开关，放大后按当前视野加载完整轨道几何。车次查询只读取所需线路片段，Windows 安装包无需包含全网数据。
- 保留独立桌面界面、余票通知、真实 GPS 和 12306 官方时刻表查询。

铁路缓存：420,540 个原始轨道段，523 个路径几何片段和 236 个地域地图片段，约 180.35 MiB；3,319 个官方车站已接入，另 85 个存在资料缺失或匹配冲突，详见[缓存说明](https://github.com/Le672/raptor/blob/master/docs/rail-network-cache.md)。

推定路径并非官方确认的实际运行径路，估算位置和速度仍可能受晚点、临时改线及限速影响。

## 下载与校验

下载 `Yukino-Rail-Watch-1.10.4-portable.exe` 后直接运行。`SHA256SUMS.txt` 提供文件校验值。
