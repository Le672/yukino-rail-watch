# Yukino Rail Watch v1.11.0

- 扩展全国城市轨道接驳：从实际有向线网发现铁路枢纽，不再只探测最近 24 个站或额外 2 个接驳站。起终点可随搜索范围纳入 8–32 个铁路接驳站，到达端正确处理单向线路。
- 接驳候选结合铁路枢纽、行程方向和轨道耗时，避免近处的小站挤掉可衔接的远端枢纽；所有实际铁路车次仍需通过当日 12306 区间查询确认。
- 铁路中转可通过城市轨道连接候选名单外、跨城市标识的铁路站；三程铁路可在两次中转中分别使用轨道接驳，继续遵守指定站、进站预留和实际乘车日期。
- 分批查询并及时展示已确认的行程，相同铁路区间的地面／轨道衔接共享请求；保留取消、未完成区间和候选范围提示。
- 新增最短轨道方案与铁路耗时比较，支持一键查看最短轨道备选。城市轨道保持可选且默认关闭，铁路方案默认优先；未知票价、首末班及停运资料不会被当作已核实。

保持独立 Windows 界面。此次更新仅面向网页与 Windows；Android／iOS 按用户要求继续暂停。
