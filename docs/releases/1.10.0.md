# Windows 1.10.0 · 车站到发大屏

- 独立 Windows 功能侧栏新增“车站大屏”，采用深色电子屏、醒目车次与时刻、双色到发状态；桌面导航与紧凑布局保持独立。
- 查询全国 12306 车站的计划到发，展示车次、始发终到、到达／出发、停靠时长、真实站台与检票口，正确处理跨日及始发／终到站。
- 接入官方逐日开行计划与正晚点查询，支持正点、早点／晚点及分钟数。候车、检票中、停检与取消仅显示官方确认状态，暂未提供时明确标注；当日不开行与临时取消分别显示。
- 支持车次／到发站筛选、近期车次、每分钟自动刷新、分页、15 秒自动翻页与大屏全屏。查询失败保留旧快照并隐藏过期实时状态。
- 本次仅更新网页与 Windows；Android / iOS 开发和发行暂停。

当前官方实时大屏接口可能返回不可用，检票状态可能显示“未提供”；请以车站现场屏幕与工作人员通知为准。
