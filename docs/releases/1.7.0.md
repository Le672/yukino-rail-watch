# Yukino Rail Watch 1.7.0

Windows 便携版：下载 `Yukino-Rail-Watch-1.7.0-portable.exe` 后直接运行，无需安装。

## 本次更新

- 无有效 GPS 测速时，结合铁路区间距离、车型与当日停站时刻，显示明确标注的预估速度。
- 包含分段线性加速、巡航与线性减速；停站显示 0，地图位置按同一速度曲线的距离积分更新。
- 优先使用设备瞬时速度；设备缺少速度字段时，用最近几秒定位短时估算，支持 Windows 系统定位。
- 支持 GPS 匹配下一停靠站、完整交互地图及 2D／卫星图切换，自定义观察时间也可查看预估速度。
- 移除旧的车载测速相关字样。

## 已有功能

- 按车次或乘车区间查询 12306 公开余票。
- 自定义检查间隔、Windows 托盘监控和系统余票通知。
- 车型与配属查询，车型 Q 版侧视图。

网页入口：[cr.yukino.bond](https://cr.yukino.bond/cr)。车型、时刻表与线路数据由 [RailGo](https://api.railgo.dev/) 提供。

下载目录中的 `SHA256SUMS.txt` 包含便携版校验值。速度预估不能获知临时停车和本次实际限速，实际运行请以列车广播和铁路信息为准。
