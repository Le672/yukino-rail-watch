# Android / iOS 1.1.0 Preview

- 新增中转行程标签页：支持广东城际、长株潭与全国官方节点，识别广州南／番禺等站群，最多三程列车及跨日连接。
- 每程显示车型插图、真实车站、官方票价、时间与余票；支持总价、时间、余票、车型排序及筛选。
- 起终点站群、站外衔接、预留时间、最长等待和指定中转站可调；站外交通费不计入铁路票价。
- 保留原生余票通知、定位和测速，手机底部导航与查询表单适配窄屏。

## 附件用途

`*-debug.apk` 可用于 Android 测试安装；`*-unsigned.aab` 尚未签名，不能直接安装或上传商店。

`*-simulator.zip` 仅供 Mac / Xcode iOS 模拟器使用，不是 IPA，不能安装到实体 iPhone。真机、TestFlight 与 App Store 需 Apple 开发者账号签名。
