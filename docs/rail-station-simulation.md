# 无完整线路时的位置模拟

2026-10-05，网页与 Windows 1.10.3。

## 使用

- 车站大屏的车次可点击打开实时位置，自动查询该车次的实际始发日期。到达与出发大屏均可使用，跨日车次不会错用车站当天作为始发日。
- 子域跳转至 `/live?train=车次&date=始发日期`；链接可刷新或分享，浏览器前进后退保持对应功能。主站保留 `/cr?view=position` 的兼容形式。
- 有完整、经过站序和距离校验的铁路折线时，继续沿铁路模拟；缺少线路时只在当前两停站之间模拟，不伪造轨道折线，不将模拟路线用作 GPS 匹配。
- 站间模拟位置与速度使用同一分段加速、巡航、减速曲线。速度依据地理距离粗估，未包含线路绕行和实际限速，页面明确标注“站间坐标＋时刻表粗估”。有效 GPS 瞬时速度或定位短时速度仍优先。
- 停站显示车站位置和零预估速度；下一站只来自 12306 停站表，跨日和有效正晚点仍按原逻辑处理。如果当前两站坐标均无法核实，则保留下一站及区间提示，不给出虚构坐标或速度。

## 坐标补充数据

`src/data/rail-station-coordinates.json` 是本地的全国铁路站点坐标快照，包含 3,204 个与 12306 规范站名及电报码匹配的站点。OSM 底层快照日期是 **2026-07-15**，规范车站列表核对于 **2026-10-05**。仅提取坐标和出处节点，不使用其车次、时刻表或余票。

数据来自 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，数据库遵循 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)。公开副本见 [独立仓库坐标文件](https://github.com/Le672/yukino-rail-watch/blob/main/src/data/rail-station-coordinates.json)。原始节点 ID 保留在各条记录中，可核查出处。

仅剥除站名末尾的“站”进行精确匹配，排除地铁站和明确非铁路站点。同名节点距离超过 1 km 时拒绝收录；不以同城邻站替代。已有线路供应商坐标优先，补充数据只填空缺，WGS84 与 GCJ-02 显式转换。完整线路仅缺站点坐标时，补齐后再次执行全部线路连接、站序和投影距离校验。

数据随软件分发，在需要时才加载，无需用户实时请求国外坐标服务。使用 `scripts/build-rail-station-coordinates.mjs` 从 OSM 公开节点及官方车站 JSON 重建；生产运行不会下载全网车次或站点资料。

## 回归验证

G2788/G2789 的公开线路资料返回空 `train` 且少于官方停站表。测试覆盖缺失的河源东、惠州北、太湖南、坐标转换、无线路加减速与地图位置一致、停站零速、GPS 优先、官方车次别名及跨日跳转。
