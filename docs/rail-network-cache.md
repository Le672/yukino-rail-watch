# 全国铁路服务器缓存

网页与 Windows 1.10.4，2026-10-07。

## 范围与使用

列车位置地图默认显示本站铁路网。勾选“铁路网”可显示或隐藏背景；查询车次后，绿色路径按 **12306 官方停站顺序** 沿真实轨道连接推定。没有 GPS 时，位置和加减速使用完整路径距离；有有效 GPS 时继续优先显示实测位置与速度。

导入按铁路类型筛选，不以建设单位、运营单位或是否国铁运营为条件。包含中国大陆、香港、澳门范围内的开放铁路数据及 12306 中老国际列车使用的老挝段，保留干线、地方铁路、城际、货运线和站场轨道。排除地铁、轻轨、有轨电车、单轨和轨道缆车，不导入规划、施工、已拆除或明确停用的轨道。

车次路径是实际轨道上的推定结果，未得到官方运行径路确认；临时改线和不同平行线路仍可能不同。相邻轨道、立交交叉点和数据断口不会凭地理距离强行连接。缺少可靠路径时保留原有站间模拟、停站和 GPS 功能，并显示缺失说明。

## 存储和加载

- 原始完整几何、连接索引、车站锚点、线路清单和覆盖审计保存在 `public/rail-network/20261004-v1/`，部署后为本站服务器的长期静态文件，不依赖运行时内存缓存存续。
- [版本入口](https://www.yukino.bond/rail-network/manifest.json)提供来源、快照日期、各文件字节数及 SHA-256。每个文件小于 25 MiB；版本文件使用一年缓存，入口每五分钟检查更新。
- 连接索引按节点和边分片。车次只读取所需的路径几何片段；低缩放显示简化概览，高缩放按视野读取保留原始几何的地域片段。完整缓存仍留在服务器，不要求用户一次下载全网。
- Windows 使用同一服务器缓存，安装包不包含整套全国地图。下载缓存文件不向第三方发送车次和站点选择。
- 当前版本的 [车站覆盖清单](https://www.yukino.bond/rail-network/20261004-v1/coverage.json)与[线路清单](https://www.yukino.bond/rail-network/20261004-v1/lines.json)可公开核查。原始 OSM way ID 保留于完整几何文件。

## 重建

```text
python -m pip install -r scripts/requirements-rail-network.txt
python scripts/build-rail-network.py --pbf china-261004.osm.pbf laos-261003.osm.pbf --stations src/data/rail-network-stations.json --version 20261004-v1
```

GitHub Actions 的 `Import nationwide railway cache` 支持手动生成并导出缓存。更新快照时同步修改固定源文件名和版本，校验覆盖及线路连接后再部署，保留原始快照信息。
