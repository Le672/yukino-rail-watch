# 余票与列车位置的数据来源

2026-10-04 起，网页、Windows 1.9.5 与 Android / iOS 1.1.4 共用以下规则。

| 内容 | 来源 | 处理方式 |
| --- | --- | --- |
| 余票、席别、区间到发时间 | 12306 | 官方余票接口；第三方不能覆盖或替代结果 |
| 票价、每程与总铁路票价 | 12306 | 优先解析官方余票价格编码，缺失时查询官方票价接口；未知值不当作零元 |
| 推荐中转节点 | 12306 | 官方中转查询按电报码解析真实车站，结合已核实的站群关系组合各程 |
| 车次、始发终到、开行日期、内部车次编号 | 12306 | 优先关键词检索，漏项或索引不可用时读取官方按日期车次表；精确匹配并去重，排除前缀和多线路歧义，不从内部编号猜车次 |
| 车站名称、电报码 | 12306 | 官方车站表，缓存 24 小时 |
| 停站表、站序、到发时刻、跨日信息 | 12306 | 官方停站接口，缓存 15 分钟并核验完整站序 |
| 正晚点、预计到达／出发时间 | 12306 | 官方未来三小时查询；每次最多两个邻近停站 |
| 计划车型、车组号 | 12306 优先 | 使用始发日 `runningDay` 请求官方车厢详情；具体车组可能调整，接口未返回车型时再使用官方未绑定日期的车型参考 |
| 客运担当 | 12306 | 官方返回铁路局及客运段，标为「担当」，不将客运段冒充车辆配属单位 |
| 缺失车型与车辆配属 | RailGo 参考补充 | 仅在官方无法取得车型时查询单车次，标为「参考车型」；官方已有车型但缺少车辆配属时不会请求第三方 |
| 铁路折线、站点地图坐标 | RailGo 补充 | 官方停站表决定下一站，坐标只用于地图匹配；缺少轨道时仍显示 GPS 和停站表 |
| 可选城市轨道线路、站序、地理接驳 | OpenStreetMap 开放网络快照 | 全国收录线路在本机计算；不替代 12306 班次，未知票价、车型、运营日期保持未知，时间只作预估，见[轨道说明](urban-rail.md) |
| 当前位置、设备瞬时速度 | 用户设备 GPS | 仅在主动开启后读取，在本机计算，不上传坐标 |

## 第三方使用范围

停止调用 RailGo 的 `getTrainMain`、`getTrainDelayAll` 和 `sts_query`。设备实时位置不来自任何列车跟踪第三方。

车型先请求同域 `/api/rail?mode=equipment&train=…&date=…` 官方网关；服务端只请求 12306，返回裁剪后的车型、车组号、客运担当及资料范围。网关与客户端均按车次和始发日缓存：成功 10 分钟，无可用车型 1 分钟；重复请求合并，客户端每批最多三个车次，网关实例的车型请求至少间隔 250 毫秒。官方按日期车次表缓存 15 分钟，最多保留三个日期，关键词检索收到 429 时提示稍后重试。

官方车型不可用时，客户端才直接请求 RailGo 单车次接口，不经公共网关中转。其响应可能包含其他字段；客户端不使用其时刻表、票额、运营信息或交路，缓存中只保留车型、配属及核对所需的车次／开行日期。成功缓存 12 小时、失败退避 15 分钟、重复请求合并，最多三个并发。铁路地图缓存 12 小时。

中途乘车使用余票响应的首站始发日期查询车型，不把上车日期当成始发日期。未绑定日期的车型及第三方车型均标为参考；悬停车型文字可查看来源与查询范围。12306 的车组号用于核对动感号涂装，明确的实际车组资料优先于港铁时刻表快照。图片、车厢内饰资料和其他无关响应字段不会保存在车型缓存或转发给客户端。

官方时刻表不可用时显示官方查询失败，不读取第三方时刻表。正晚点不可用或超出三小时范围时说明暂无官方结果，再按官方计划时刻估算。官方余票和停站表先显示，车型补充不阻塞到票通知。

## 官方依据

- [12306 停站表查询](https://kyfw.12306.cn/otn/czxx/init)
- [12306 按日期车次表](https://kyfw.12306.cn/otn/queryTrainInfo/getTrainName?date=2026-10-04)
- [12306 始发日车型与车组资料](https://kyfw.12306.cn/wxxcx/openplatform-inner/miniprogram/wifiapps/appFrontEnd/v2/lounge/open-smooth-common/trainStyleBatch/getCarDetail?carCode=&trainCode=G6003&runningDay=20261004&reqType=form)
- [12306 正晚点查询与三小时范围说明](https://hzfw.12306.cn/zgzfw/resources/web/zwdcx.html)
- [RailGo 单车次资料说明](https://api.railgo.dev/366464494e0)

这些是官方公开页面所用的接口，并非稳定性承诺；格式变化时保留错误提示，实际到发以铁路广播和站内显示为准。

多程中转的站群、时间预留、排序与查询范围见[中转说明](rail-transfer.md)。站群只是步行或站外连接，每程保留自己的官方车站与车次，不把不同电报码伪装成相同车站。
