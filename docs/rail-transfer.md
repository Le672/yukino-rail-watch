# 多程中转与排序

网页、Windows 1.9.3、Android / iOS 1.1.2 提供全国中转入口。输入首程实际乘车日期和两个官方车站，默认最多换乘一次，可改为两次、三段列车；支持指定任意一个或两个中转节点，不限制省份、地区或列车等级。

## 车站与换乘

每程查询保持 12306 官方电报码。官方余票接口有时扩展同城车站，服务端严格过滤首尾电报码，禁止把广州白云出发显示成广州南出发。

| 衔接 | 类型 | 默认方向预留 |
| --- | --- | --- |
| 广州南 → 番禺 / 反向 | 相邻站群 | 25 / 35 分钟 |
| 广州新塘 → 新塘南 / 反向 | 相邻站群 | 20 / 30 分钟 |
| 虎门 → 虎门北 / 反向 | 相邻站群 | 25 / 35 分钟 |
| 广州北 → 花都 / 反向 | 相邻站群 | 20 / 30 分钟 |
| 肇庆东 → 鼎湖东 / 反向 | 相邻站群 | 20 / 30 分钟 |
| 惠州 → 小金口 / 反向 | 相邻站群 | 20 / 30 分钟 |
| 东莞东 → 常平东 / 反向 | 站外步行，需过路口 | 30 / 40 分钟 |
| 全国官方同城异站（含长株潭、京津、沪杭、成渝、东北、西北等） | 站外衔接 | 城区站默认 90 分钟，可设 45–360 分钟；未核实城区范围的站至少 180 分钟 |
| 相同电报码 | 同站换乘 | 默认 20 分钟，可设 10–180 分钟 |

这些时间是本应用的规划预留值，包含出闸、步行、安检与检票；不是运营方公布的最短换乘承诺，也不是实时路况预测。全国同城异站可关闭，地面交通自行安排，费用不计入铁路票价。起终点纳入已核实相邻站群可独立关闭，界面显示实际乘车站及步行段，起终点不会自动改成其他同城车站。

同城按官方车站表的城市名称与城市标识判断；城市名称相同但城市代码冲突时不连接，缺少城市资料也不推断。不同电报码保持独立，只有已核对的七组基础设施关系使用步行预留；例如北京南与黑山寺不能按相邻站群处理，后者的站外预留至少 180 分钟。同城并不表示已有地面直达路线，尤其直辖市及大面积城市的交通路线需另行确认。

## 数据及搜索

- 官方 `zzzcx/query` 推荐节点与官方车站表结合，不相信“长沙”等城市式标签，按其返回的电报码解析真实车站。
- 当前官方车站表实查包含 3404 站、432 个城市标识（2026-10-03；界面随官方表动态更新）。每一个官方车站都进入全国候选库；主站、方向站、全国干线枢纽、城际／市域站点及同城异站用于排序发现，即使官方推荐非空也保留其他全国候选。
- 干线拓扑只用于安排候选查询顺序，不能证明车次存在。所有实际乘车段、日期、站名、时间、票价和余票都必须通过当日 12306 区间查询；不依据拓扑生成虚构车次。候选包括西藏、新疆、青海、海南、东北等地区，支持 12306 提供的高铁、普速、城际和市域列车；不伪造未接入 12306 的地铁或城际班次。
- 官方 `train_list.js` 实查仍为 2022-08-17 至 2022-09-01 的静态目录，因此不作为当前车次或运行关系依据，也不会因目录缺少某站就排除该站。网页当前推荐接口、车站表及余票结果才决定行程。
- 区间余票缓存 30 秒，最多三个并行查询；同一服务实例的官方余票请求至少间隔 250 毫秒，并合并会话初始化。连续八个区间失败时停止继续请求并保留已有方案，不能把服务异常当作没有路线。同站、相邻站群和注册的站外连接参与组合；每程日期依据真实历时跨日推进。
- 排除错过发车、预留不足、等待过长、重复乘坐同一内部车次和返回已途经车站的路线。
- 默认检查 64 个优先候选站，可选择 128、256、512 站；结果提供“扩大范围重新查询”。单次区间请求上限为候选站设置的八倍，两次中转自动连接上限为两倍，最多保留 50000 个组合。每次显示全国候选总数、已选站数、实际请求数和未完成区间；扩大搜索会重新核对余票，不能将旧结果当作当前余票。
- 自动结果不承诺穷尽全网所有组合；范围截断、未完成的区间及连接均明确提示。可指定任何官方站名补查所选路径，排序在结果分页前进行。查询范围限制适用于所有地区，不是省份或城市白名单。

## 票价及余票

优先解析官方余票中的十字符 `yp_info_new` 价格编码，与当前官网 `queryLeftTicket_end_js` 的 `bI` 解码规则一致：第 2–6 位为十分之一元价格，第 7 位 `3` 表示无座。缺失时用官方 `queryTicketPrice`，参数从该车次在所选区间的真实余票记录提取；不接受用户提交未经核对的内部车次、站序。

城际 C/S 不对号服务可能把余票放在 `wz_num`，价格放在二等座 O 类型。只有官方车次为 C/S、`seat_types` 精确为 O、其他席别均未提供且有无座资料时，才把 O 票价关联至该不对号席别；不能套用于普通高铁无座或其他类型票价。

总铁路票价逐程相加。选择具体席别时只使用该席别；任意席别使用各程最低适用票价。若适用席别票价不完整，则总价未知，排在完整总价后；不会将缺失价格当作零元。站外交通费另计。

按余票排序使用各程可用数量的瓶颈，整程有票要求每程均有关注席别。官方“有”仅表示未给精确数，不显示伪造数量。车型仍由 RailGo 单车次缓存补充；不使用其时刻表、票额或报价。车型筛选默认至少一程匹配，可改为每程都匹配。
