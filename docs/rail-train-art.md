# 车型 Q 版首车侧视图

2026-09-29 修订：按[中国动车组车型目录](https://www.china-emu.cn/Trains/ALL/)逐项重新核对实拍，重绘 33 款外观，另恢复 10 款原版参考图并补齐 14 款 CR200J 参考图，共 57 款；具体版本无法确认的图旁显示待核实标注。网页与 Windows 1.3.3 使用同一目录及 SVG。

## 绘制依据

每款车型的资料页、参考版本和摄影者记录在 `src/data/train-art.json`。页面底部「车型图示说明」可查看当前结果的资料页和补充照片。完整核对清单在 [rail-train-art-references.json](rail-train-art-references.json)，包含网站的示例头像地址、实拍地址和署名，仅保存引用信息，没有转载图片。

本站原创 SVG 根据实拍的物理外观绘制，不描摹或转载中国动车组的正面萌化头像。采用侧视图，压缩首车纵向比例；窗数、小部件和转向架经过简化。它是资料页版本的外观参考，不能证明查询车次使用的具体车组编号、制造批次或特殊涂装。

本次重点修正：

- 普通 CR400AF：圆润下鼻、三角侧驾驶窗、红色侧楔和窗下红线，去掉错误的窗顶贯通红带。
- CR400AF-C：按资料页 CR400AF-C-2214 的上部红金弧带、窗下红线绘制，不套用 AF-Z 的波浪涂装。
- AF-Z / AZ / BZ / AS / BS / AE：银灰车身，按实际位置绘制红金飘带。
- 普通 CR400BF：泪滴形侧驾驶窗、金色侧楔，保留窗下宽窄双金线。
- BF-AZ / BZ / GZ 与 AS / BS：分别绘制三角窗框、宽红飘带及金色弧线。
- CR300AF / BF：独立核对短鼻轮廓，保留蓝白渐变及各自红色、金色色带。
- CRH380A / AL：银灰鼻部，去掉将天空反光误画成蓝色鼻部涂装的问题。
- CRH1A、1A-A、2G、3C、380B 系列、380CL、380D、5A：分别核对驾驶端轮廓、侧窗和窗带；CRH5A 使用独立客窗，不能加连续黑色窗带。

## 无法区分版本时保留原图并标注

查询接口目前只提供车型名称，未提供车组编号或明确代际。以下 10 个型号恢复 2026-09-28 的原版插画，图旁以琥珀色标注「参考外观 · 版本待核实」。悬停及页底说明列出差异，图片仅供参考，不能确认当前车次的实际版本；余票与车型文字不受影响：

| 名称 | 资料页中的区别 |
| --- | --- |
| CR400AF-S | 原 AF 系列与智能系列均使用此名称，头型与涂装不同 |
| CR400BF-S | 原 BF 系列与智能技术提升型头型、涂装不同 |
| CR400BF-A | 普通座席版与纵向卧铺版本外观不同 |
| CR400BF-Z | 普通版、亚运版、双层与纵向卧铺版本不能只凭名称区分 |
| CRH1B | Regina 与 1E 头型 |
| CRH2A | 原型、统型与 NG 头型 |
| CRH2B | 原头型与 2A 头型 |

CRH1E、CRH2C、CRH2E、CRH3A 及只写 CR200J 而无代际的名称仍不提供其他型号替代图。未知后缀、未知编组描述、多型号冲突及车次号均不匹配。

## CR200J 参考图及编组名称

新增 14 款：CR200J1-A/3-A（短编与长编）、CR200J2-A、CR200J1-B/2-B/3-B、CR200J1-C/3-C（短编与长编）、CR200J2-C（长编）及 CR200J1-D。

`CR200J1-C(长编)`、`CR200J1-C（长编）`、`CR200J1-C (长编组)`、`CR200J1-C(18编组)` 匹配同一款长编动力车参考图，保留接口返回的名称显示。短编与长编分别收录，不用有客室窗的控制车冒充长编动力车。CR200J2-A、2-B 和 1-D 的资料展示动力端，因此这些短编型号也以动力车为参考。

A/B 型使用实拍中的绿色车身和黄色侧带，C/D 型使用白底、绿色窗区和红色双曲线。所有新增图均标注「参考外观 · 版本待核实」，不确认本次列车的运行方向、车组批次和特殊涂装。资料记录在 [cr200j-art-references.json](cr200j-art-references.json)，图片未转载。B 型长编资料为未运营的样车，且页内使用其他车型照片，本次不把它们计入运营车型参考图。

`aliases` 只登记有依据的编组名称；不任意去掉括号、车型代际或后缀。CR200J 图由 `scripts/draw-cr200-art.mjs` 绘制，由主绘图脚本一并调用。

## 后续维护

新增型号须核对其独立实拍，保存资料页、照片署名和明确的外观版本，增加绘图参数，再运行 `node scripts/draw-train-art.mjs`。参考图用 `accuracy: "reference"` 与 `referenceNote` 标注；旧版 SVG 会保留，新增 CR200J SVG 由独立绘图模块生成，主绘图脚本保留这些 SVG，不覆盖为已核对图；缺少原图时会报错。补充车辆编号或代际依据并完成重绘后，才能将该条目改为 `accuracy: "reviewed"`。
